Files are read and converted in your browser with Mediabunny, using the browser's built-in codecs. MP3 and FLAC are encoded with WebAssembly encoders; AAC (M4A) uses the browser's own encoder where it has one. Input support depends on your browser.

Frequently Asked Questions

Is my audio file uploaded to a server?
No. All conversion happens directly in your browser, using its built-in codecs and WebAssembly. Your files never leave your device. There is no server-side processing — check the network tab in DevTools to verify.
What is the maximum file size?
The converter reads the file in pieces instead of loading it whole, so large audio files and long videos work in current browsers. Older browsers decode the whole file in memory, which limits them to roughly 100–200 MB. For very large files, consider using our CLI tool: go-audio-converter — a pure Go converter with no file size limits.
What audio quality can I expect?
WAV and FLAC are lossless: FLAC keeps the same sound in a file about half the size. MP3 and M4A at 192 kbps sound high quality for most uses, and you can choose up to 320 kbps.
Does it work offline?
The converter works offline once the page and its encoders have loaded. Bookmark this page for quick access.
Can I use a command-line tool instead?
Yes! Our open source go-audio-converter is a pure Go audio converter — no FFmpeg, no CGO, single binary. It supports WAV, MP3, FLAC conversion and runs on any platform including as WebAssembly.
