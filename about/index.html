About AudioTools.dev

AudioTools.dev is a set of free audio tools that run entirely in your web browser. Your files are processed on your device and are never uploaded. There are no accounts, no usage limits and no ads, and the code is open source under the MIT license.

What you can do here

  • Audio Converter — audio or video to MP3, M4A, WAV or FLAC
  • Audio Trimmer — cut a part of a recording on a waveform
  • Audio Joiner — merge files, with optional crossfade
  • Volume Booster — make quiet audio louder or normalize it
  • Speed Changer — 0.25× to 4× without changing pitch
  • Audio Compressor — smaller MP3 files at a bitrate you choose
  • Text to Speech — read text aloud in 50+ languages
  • Voice to Text — live dictation, or private transcription with Whisper on your device

Who makes it

AudioTools.dev is built and maintained by Roman Gordienko, a backend developer working with Go and Python. It is an independent open-source project, started in January 2026. The changelog lists everything that has shipped since.

How your files stay on your device

Every tool decodes, edits and encodes audio inside your browser with the Web Audio API and WebAssembly. Nothing is sent to a server, because there is no server: the site is a set of static pages on GitHub Pages.

You can check this yourself:

  1. Open your browser's developer tools (F12) and go to the Network tab.
  2. Process a file with any tool.
  3. You will see no request that carries your audio.

What the site does load from the network, so the list is complete:

  • the pages themselves, from GitHub Pages;
  • the Archivo typeface, from Google Fonts;
  • the Whisper speech model from Hugging Face and the Transformers.js library from jsDelivr, once, when you use Private mode in Voice to Text;
  • Google Analytics and Yandex Metrika for anonymous page-view statistics (see the privacy policy).

One exception is worth knowing: live dictation in Voice to Text uses your browser's speech engine, and Chrome and Safari may send that audio to Google or Apple. Private mode does not.

How it is built

  • Decoding and processing: Web Audio API (OfflineAudioContext)
  • Reading and encoding audio and video: Mediabunny (MPL-2.0, served from this site), with WebAssembly encoders for MP3 and FLAC
  • Speed change without pitch shift: WSOLA time-stretching
  • Private transcription: Whisper (Base, Small, large-v3-turbo) via Transformers.js in a Web Worker, on WebGPU where available
