Privacy Policy

Last updated: February 10, 2026

The Short Version

Your audio files never leave your device. We don't collect, store, or process your audio data on any server. All audio conversion and transcription happens directly in your browser.

What Data We Collect

AudioTools.dev collects minimal, anonymous analytics data to understand how the site is used and improve it:

  • Google Analytics — collects anonymous page view data, browser type, device type, country. No personally identifiable information. You can opt out using browser extensions like Google Analytics Opt-out.
  • Yandex Metrika — similar anonymous analytics for understanding user behavior. Data is aggregated and anonymized.

We do not collect:

  • Names, emails, or any personal information
  • Audio files or their contents
  • Transcription results
  • Conversion history
  • IP addresses (analytics tools may collect these per their own policies)

How Audio Processing Works

All AudioTools work entirely in your browser using client-side JavaScript and Web APIs:

  • Audio Converter — uses Web Audio API for decoding and lamejs/WebAssembly for encoding. Your files are processed in browser memory and never uploaded.
  • Voice to Text — uses the browser's built-in Web Speech Recognition API. Audio data is handled by your browser, not our servers.

You can verify this by checking the Network tab in your browser's DevTools — no audio data is transmitted.

Cookies

AudioTools.dev itself does not set cookies. Google Analytics and Yandex Metrika may set cookies for analytics purposes. These are standard analytics cookies used across the web.

Third-Party Services

  • Google Analytics — website analytics
  • Yandex Metrika — website analytics
  • GitHub Pages — site hosting

Children's Privacy

AudioTools.dev does not knowingly collect information from children under 13. The tools are freely available without any account or data collection.

Changes to This Policy

We may update this policy occasionally. Changes will be posted on this page with an updated date.

Contact
