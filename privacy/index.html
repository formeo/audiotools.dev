Privacy Policy

Last updated: October 29, 2026

The short version

Your audio files never leave your device. We don't collect, store, or process your audio data on any server. All audio conversion and transcription happens directly in your browser.

What data we collect

AudioTools.dev collects minimal, anonymous analytics data to understand how the site is used and improve it:

  • Google Analytics — collects anonymous page view data, browser type, device type, country. No personally identifiable information. You can opt out using browser extensions like Google Analytics Opt-out.
  • Yandex Metrika — similar anonymous analytics for understanding user behavior. Data is aggregated and anonymized.
  • Tool events — anonymous counts sent to Google Analytics, such as “a file was processed in the Audio Compressor”, which tool the homepage helper suggested and whether its settings were kept. They contain tool names and options only: never file names, file contents or what you type into the helper.

We do not collect:

  • Names, emails, or any personal information
  • Audio files or their contents
  • Transcription results
  • Text you type into the homepage helper (it is read in your browser and never sent)
  • Conversion history
  • IP addresses (analytics tools may collect these per their own policies)

How audio processing works

All AudioTools work entirely in your browser using client-side JavaScript and Web APIs:

  • Audio Converter — uses the browser's built-in codecs and WebAssembly encoders (Mediabunny, served from this site) for decoding and encoding. Your files are processed in browser memory and never uploaded.
  • Voice to Text — uses the browser's built-in Web Speech Recognition API. Audio data is handled by your browser, not our servers. In Private mode, speech is transcribed by the Whisper model running in your browser; the model files are downloaded from Hugging Face (or, where Hugging Face can't be reached, from AudioTools.dev itself), and your audio is never sent anywhere. If the model fails to load, an anonymous analytics event records which model, the device type (CPU or graphics card) and whether the download failed; nothing about your audio.
  • Vocal Remover — the song is separated in your browser by the SCNet or SCNet-large model with ONNX Runtime Web; the model and the runtime are downloaded from this site once, and the song is never uploaded. A test option, shown only when the page is opened with ?model=mel-roformer, downloads its model from Hugging Face instead; the song still stays on your device. On that page a small service worker adds isolation headers so the separation can use several processor threads; it stores nothing.

You can verify this by checking the Network tab in your browser's DevTools — no audio data is transmitted.

When you drop a file on the homepage helper and pick a tool, the file is handed to that tool through your browser's local storage (IndexedDB) and deleted as soon as the tool opens it. It never leaves your device.

Cookies

AudioTools.dev itself does not set cookies. Google Analytics and Yandex Metrika may set cookies for analytics purposes. These are standard analytics cookies used across the web.

Third-party services

  • Google Analytics — website analytics
  • Yandex Metrika — website analytics
  • GitHub Pages — site hosting
  • Google Fonts — the Archivo typeface

Children's privacy

AudioTools.dev does not knowingly collect information from children under 13. The tools are freely available without any account, and no personal information is requested.

Changes to this policy

We may update this policy occasionally. Changes will be posted on this page with an updated date.
