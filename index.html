What is Audio Tools?

Audio Tools is a collection of free, open source utilities for audio processing. Whether you need to identify unknown music tracks, remove noise from audiobook recordings, convert audio files between formats, or transcribe speech to text — Audio Tools has you covered.

Key Features

🎧 Music Recognition Identify thousands of tracks in bulk using Shazam. Auto-tag files with artist, title, and album metadata.
📚 AI Noise Removal Clean audiobooks using MDX-Net neural networks. Remove background music, noise, and recording artifacts.
🔄 Audio Conversion Convert WAV, FLAC, OGG to MP3 with a pure Go binary. No ffmpeg, no dependencies, just copy and run.
🎤 Voice to Text Transcribe speech to text online for free. 60+ languages, works in browser, no data uploaded.

Why Open Source?

All command-line tools are fully open source under permissive licenses. You can inspect the code, contribute improvements, or fork for your own projects. The online Voice to Text tool runs entirely in your browser — your audio data never leaves your device.

Technology Stack

The projects are built with Python (asyncio, PyTorch, MDX-Net) for AI-powered audio processing and Go for high-performance, zero-dependency audio conversion. The web tools use modern browser APIs like the Web Speech API for speech recognition without any server-side processing.
