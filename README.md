# 🎵 Audio Tools

Open source audio processing ecosystem — [audiotools.dev](https://audiotools.dev)

## Online Tools

- **[Voice to Text](https://audiotools.dev/voice-to-text/)** — Free online speech-to-text transcription. 60+ languages, browser-based, no data uploaded.

## Open Source Projects

| Project | Description | Status |
|---------|-------------|--------|
| [music_recognition](https://github.com/formeo/music_recognition) | Bulk music identification via Shazam | ✅ Ready |
| [audiobook-cleaner](https://github.com/formeo/Audiobook-Cleaner) | AI audiobook noise removal (MDX-Net) | ✅ Ready |

## Tech Stack

- **Python** — asyncio, PyTorch, MDX-Net
- **Go** — Pure Go, zero dependencies
- **Web** — Web Speech API, vanilla HTML/CSS/JS
