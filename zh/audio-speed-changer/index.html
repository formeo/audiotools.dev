放慢或加快音频，音调不变

音频变速是一个在线放慢、加快音频的工具。它能把任意录音调到 0.25 倍（慢四倍）到 4 倍速，并保持原来的音调：放慢的歌曲不跑调，加快的人声也不会变尖。它在浏览器中运行，不上传任何内容。

如何放慢音频文件

  1. 把 MP3、M4A、WAV 或其他音频文件拖到上面的框中。
  2. 选择预设（0.5x、0.75x、1.25x、1.5x、2x），或用滑块设置 0.25x 到 4x 之间的任意速度。
  3. 点击“应用并处理”，试听结果。
  4. 下载为 MP3 或 WAV。

放慢歌曲来扒歌练琴

吉他独奏、钢琴段落和鼓的加花，用 0.5x–0.75x 学起来更容易。音调不变，所以可以按原调跟着弹。想反复练某一段，先用音频剪辑把它剪出来，再到这里放慢。

放慢语音，用于学外语和听写

在 0.75x 下，母语者的语速更容易跟上，听起来也不别扭。手动整理采访或讲座时，0.5x–0.75x 能让您跟上说话人的节奏。

加快播客、讲座和语音消息

1.5x 时，60 分钟的讲座只需 40 分钟；2x 时只需 30 分钟。得到的是一个更短的文件，可以保存并在任何地方播放，而不只是播放器里的倍速设置。

音调保持不变

简单的变速会连带改变音调：加快变高，放慢变低。本工具使用 WSOLA（波形相似叠加）时间伸缩，只改变速度、保留原有音调，人声和乐器听起来都很自然。

支持的格式

MP3、M4A/AAC、WAV、FLAC、OGG 和 WebM：浏览器能播放的都可以。结果保存为 MP3 或 WAV；如需 M4A 或 FLAC，之后用音频转换器转换即可。

想要文字？语音转文字可以在您的设备上转录录音。想先把几段录音连起来，请用音频合并。

常见问题

如何在不改变音调的情况下放慢音频？
把文件拖到这里，选择低于 1x 的速度（例如 0.75x），点击“应用并处理”。WSOLA 时间伸缩会保留原有音调；结果可下载为 MP3 或 WAV。
可以放慢 M4A 或 WAV 文件吗？
可以。MP3、M4A/AAC、WAV、FLAC、OGG 和 WebM 都支持。结果保存为 MP3 或 WAV。
扒歌用什么速度最好？
从 0.5x–0.75x 开始，熟练后再逐步提高速度。音调不变，可以按原调跟着弹。
可以加快播客或语音消息吗？
可以。选择 1.25x–2x 并下载结果。60 分钟的录音在 1.5x 下只需 40 分钟。
我的音频会被上传吗？
不会。所有处理都通过 Web Audio API 在您的浏览器中完成。
