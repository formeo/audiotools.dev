免费把音频转成文字

语音转文字有两种方式。私密模式用在浏览器中运行的 Whisper 语音模型转录音频文件和录音，音频不会离开您的设备。实时听写用浏览器的语音引擎实时记下您说的话。两种方式都免费，无需账号，没有时长限制。

如何转录音频文件

  1. 在顶部选择录音所说的语言。
  2. 在私密模式中选择模型：Base 更快，Small 更准确；在支持 WebGPU 的电脑上，Turbo 效果最好。
  3. 点击“转录文件”并选择音频或视频文件（MP3、WAV、M4A、OGG/Opus 语音消息、MP4…），或点击“录音并转录”使用麦克风。
  4. 首次使用时模型会下载一次（80–250 MB；Turbo 约 1.6 GB），之后由浏览器保存。
  5. 复制文字，或下载为 .txt 文件。

语音消息转文字

从 WhatsApp 或 Telegram 保存语音消息（.opus 或 .ogg 文件），然后用“转录文件”打开。转录在您的设备上完成，这对私人对话很重要。

私密模式还是实时听写？

  • 私密模式——适合文件和录音。在您的设备上运行，模型下载后可离线使用。在较慢的手机上，长录音需要一些时间。
  • 实时听写——边说边出文字。使用浏览器的语音引擎，在 Chrome 和 Safari 中可能会把音频发送给 Google 或 Apple，并且需要联网。

支持的语言

Whisper 能识别约 100 种语言，包括中文、英语、西班牙语、俄语、德语、法语、日语、韩语、阿拉伯语、印地语和葡萄牙语。实时听写支持 60 多种语言和地区变体，具体列表取决于您的浏览器。

使用场景

  • 会议、讲座和采访的笔记
  • 不方便听、更想看的语音消息
  • 口述邮件、消息和文档
  • 视频字幕的初稿
  • 解放双手的文字输入

隐私

私密模式在您的设备上运行 Whisper 模型：模型从 Hugging Face 下载一次（无法连接 Hugging Face 时改从 AudioTools.dev 下载），您的音频不会离开浏览器。实时听写使用浏览器的语音引擎，可能会把音频发送给浏览器厂商。AudioTools.dev 没有后端——我们从不接收您的音频或转录文字。

浏览器兼容性

私密模式适用于最新版本的 Chrome、Edge、Firefox 和 Safari。实时听写适用于 Chrome、Edge 和 Safari；Firefox 不支持。

需要反过来？文字转语音可以朗读文字。想先从视频中提取声音或缩小长录音，请用音频转换器或音频压缩。

常见问题

如何把录音转成文字？

选择语言，在私密模式中点击“转录文件”并选择录音。Whisper 会在浏览器中转录，之后可以复制文字或下载为 .txt 文件。

可以转录 WhatsApp 或 Telegram 语音消息吗？

可以。从聊天中保存语音消息（.opus 或 .ogg 文件），用“转录文件”打开即可。转录在您的设备上完成，绝不上传。

我的语音数据会被发送到服务器吗？

私密模式不会：Whisper 在浏览器中运行，音频不会离开您的设备。实时听写使用浏览器的语音引擎，在 Chrome 和 Safari 中会把音频发送给 Google 或 Apple。AudioTools.dev 没有后端，不存储任何内容。

免费吗？有时长限制吗？

免费，没有限制。长录音只是需要更久，取决于您的设备和所选模型。

支持哪些语言？

私密模式（Whisper）能识别约 100 种语言。实时听写支持 60 多种语言，具体取决于您的浏览器。

手机上能用吗？

能。两种模式都适用于 Android 上的 Chrome 和 iPhone 上的 Safari。私密模式需要下载一次模型（80–250 MB），首次使用请连接 Wi-Fi。

转录准确吗？

对于清晰的语音，Base 足以用于笔记和草稿。Small 的错误明显更少，尤其是英语以外的语言；Turbo（在支持 WebGPU 的电脑上）最准确。背景噪音、音乐和多人同时说话会降低准确度。
