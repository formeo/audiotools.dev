    在线合并 MP3 等音频文件

    添加文件、排好顺序，下载一个文件即可。音频合并完全在浏览器中运行：文件在您的设备上解码、拼接和编码，因此不上传任何内容，没有大小配额，也不用排队等待。

    如何合并音频文件

    1. 把文件拖放到上方的框中，或点击选择。之后还可以用“添加更多文件”继续添加。
    2. 拖动音轨排出想要的顺序，或使用箭头调整。
    3. 可选：设置最长 3 秒的淡入淡出，让过渡更平滑。保持 0 则直接衔接。
    4. 点击“合并并下载”，将结果保存为 MP3（192 kbps）或 WAV。

    可以合并哪些文件

    MP3、WAV、M4A/AAC、FLAC、OGG 和 Opus 文件可按任意顺序混合，只要浏览器能播放即可。从 WhatsApp 或 Telegram 保存的语音消息（.opus、.ogg）在支持 Opus 的浏览器中可用，例如 Chrome、Edge 和 Firefox。单声道和立体声可以混合，不同采样率的文件会自动统一。

    常见用途

    • 给一期播客接上片头和片尾
    • 把几条语音消息合成一段录音
    • 把有声书的各章合成一个文件
    • 把多首歌曲做成串烧，中间加淡入淡出
    • 按顺序拼接音效或铃声片段

    在 iPhone 和 Android 上使用

    无需安装任何应用：在 iPhone 的 Safari 或 Android 的 Chrome 中打开本页，从手机添加文件，下载合并后的文件即可。

    限制

    合并过程中，所有音轨都保存在设备内存里。大多数电脑处理一两个小时的音频没有问题；在手机上，过长的合并可能内存不足，可以分几次合并。

    想让合并后的文件更小，用音频压缩；想先剪掉一部分，用音频剪辑；需要 M4A 或 FLAC，用音频转换器；某段录音比其他的小声，用音量增强器。

    常见问题

    如何把多个 MP3 合并成一个？
    添加 MP3 文件，排好顺序，可选设置淡入淡出，然后点击“合并并下载”。您会得到一个在浏览器中生成的 MP3 或 WAV 文件。
    可以合并不同格式的文件吗？
    可以。MP3、WAV、M4A、FLAC、OGG 和 Opus 可以在一次合并中混用。每个文件由浏览器解码，结果保存为 MP3 或 WAV。
    可以合并 WhatsApp 或 Telegram 的语音消息吗？
    可以。从聊天中保存语音消息（.opus 或 .ogg 文件），然后添加到这里。Chrome、Edge 和 Firefox 可以播放这类文件，部分旧版 Safari 不行。
    合并会降低音质吗？
    保存为 WAV 时，解码后的音频保持不变。保存为 MP3 时会以 192 kbps 重新编码，对语音和大多数音乐来说听起来与原文件相同。
    文件数量有限制吗？
    没有固定限制。唯一的限制是设备内存，因为合并时所有音轨都保存在内存中。
    我的音频会被上传吗？
    不会。所有合并都通过 Web Audio API 在您的浏览器中完成。
