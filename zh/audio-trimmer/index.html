免费在线音频剪辑

AudioTools 音频剪辑可以直接在浏览器中剪切任意音频文件。拖入 MP3、WAV、FLAC 或 OGG 文件，查看波形，拖动剪辑手柄选出需要的部分，然后下载结果。不上传到任何服务器——所有处理都使用 Web Audio API。

如何剪辑音频文件

拖放或选择音频文件，会出现可视化波形以及蓝色（开始）和红色（结束）剪辑手柄。拖动手柄或输入精确时间来确定剪辑范围。点击“试听”收听所选部分，再点击“剪切并下载”保存为 MP3 或 WAV。

支持的格式

输入：MP3、WAV、FLAC、OGG、AAC、M4A、WebM——浏览器能解码的任何格式。输出可选 MP3（192 kbps）或 WAV（无压缩、无损）。音频转换器支持更多格式。

隐私

您的音频文件不会离开您的设备。剪辑使用 Web Audio API 的 OfflineAudioContext，完全在浏览器中处理音频。没有服务器，也不上传——我们不会收集您的音频。

常见问题

如何在线剪辑音频文件？
拖放或选择文件，拖动波形上蓝色的开始手柄和红色的结束手柄，然后点击“剪切并下载”。剪辑后的文件保存为 MP3 或 WAV。
我的音频会上传到服务器吗？
不会。所有处理都通过 Web Audio API 在浏览器中完成，文件始终留在您的设备上。
可以剪辑哪些格式？
浏览器支持的任何格式：MP3、WAV、FLAC、OGG、AAC、M4A、WebM。输出为 MP3 或 WAV。
