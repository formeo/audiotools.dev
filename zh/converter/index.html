常见问题

我的音频文件会上传到服务器吗？
不会。所有音频转换都通过 Web Audio API 和 JavaScript 在您的浏览器中完成，文件永远不会离开您的设备。没有任何服务器端处理——您可以在开发者工具的“网络”面板中自行验证。
最大文件大小是多少？
由于处理在浏览器中进行，限制取决于设备的可用内存。大多数现代设备可以顺利处理 100–200 MB 的文件。对于超大文件，可以使用我们的命令行工具 go-audio-converter——纯 Go 实现，没有文件大小限制。
转换后的音质如何？
WAV 输出是无损的，与解码后的音频完全一致。192 kbps 的 MP3 编码可满足大多数用途的高质量需求，最高可选 320 kbps。
可以离线使用吗？
页面加载完成后即可离线使用（MP3 编码库需要加载一次）。建议收藏本页面以便快速访问。
可以使用命令行工具吗？
可以！我们的开源项目 go-audio-converter 是纯 Go 编写的音频转换器——无需 FFmpeg、无需 CGO、单个可执行文件。支持 WAV、MP3、FLAC 转换，可在任何平台运行，也可编译为 WebAssembly。
