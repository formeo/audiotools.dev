把任意歌曲做成慢速混响版

慢速混响（slowed + reverb）是把歌曲放慢一点、音调变低，再放进大房间里的那种梦幻、空旷的声音。这个工具可以用您设备上的任何歌曲来制作：选一个预设，一边播放一边调节速度和混响，然后下载 MP3 或 WAV。它也能做加速版和 Nightcore 版。一切都在浏览器中用 Web Audio API 完成，歌曲绝不上传。

如何制作慢速混响版

  1. 把歌曲拖到上面的框中，或点击选择：MP3、M4A、WAV、FLAC、OGG 或视频。
  2. 点击“慢速混响”，然后按播放。
  3. 调节速度、混响量和房间大小，直到满意为止。
  4. 点击“生成文件”，下载为 MP3 或 WAV。

各项设置的作用

  • 速度：0.5× 到 1.5×。低于 1× 时歌曲更慢、音调更低；大多数慢速混响版在 0.8× 到 0.9× 之间。
  • 混响：在歌曲本身之外能听到多少房间的声音，从完全没有到以房间声为主。
  • 房间大小：混响持续多久，从 1 秒（小房间）到 8 秒（大厅）。

加速版和 Nightcore 版

高于 1× 时歌曲更快、音调更高。“加速”使用 1.25×，这是抖音、TikTok 上加速版歌曲常见的速度；“Nightcore”使用 1.3× 并加一点混响。

音调随速度变化

就像唱片或磁带一样，歌曲放慢时音调变低，加快时变高：这正是慢速混响的标志性声音。如果想改变速度但保持原来的音调，请使用音频变速。

隐私

歌曲在您的浏览器中解码、变速并加上混响，房间的回声也在您的设备上计算。不会向任何服务器发送数据，完成的文件直接从页面保存。

想先做一个伴奏版？人声消除可以去掉歌曲里的人声。只想保留最精彩的部分，可以用音频剪辑剪出来。

常见问题

如何制作慢速混响版歌曲？
把歌曲拖到本页，点击“慢速混响”预设，边听边调节速度和混响，然后点击“生成文件”并下载 MP3 或 WAV。
慢速混响一般用多大的速度？
通常是 0.8× 到 0.9×。预设使用 0.85×，混响 35%，房间 4 秒；慢于 0.75× 时声音开始发浑。
可以做加速版或 Nightcore 版吗？
可以。选择“加速”（1.25×）或“Nightcore”（1.3× 加一点混响），也可以设置最高 1.5× 的任意速度。
放慢歌曲会改变音调吗？
会，这是有意为之：音调随速度变化，就像唱片一样。如果想放慢但不改变音调，请使用音频变速。
我的歌曲会被上传吗？
不会。一切都在您的浏览器中用 Web Audio API 完成，歌曲绝不离开您的设备。
可以把结果发到抖音或 B 站吗？
文件可以保存和播放。能否公开发布取决于原曲的版权，和任何翻混作品一样。
