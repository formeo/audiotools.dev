免费去掉歌曲里的人声，无需上传

人声消除会把一首歌分成两个文件：去掉演唱的伴奏，以及单独的人声。它在浏览器中运行开源音乐分离模型 SCNet，歌曲始终留在您的设备上。无需账号，无需排队，歌曲数量不限。

如何制作伴奏或卡拉 OK 伴奏

  1. 把歌曲拖到上面的框中：MP3、M4A、WAV、FLAC、OGG 或视频。
  2. 点击“消除人声”。首次使用时会下载一次模型（13 MB）。
  3. 试听两个结果，把伴奏、人声或两者下载为 MP3 或 WAV。

适合做什么

  • 卡拉 OK 和练唱——跟着原曲伴奏演唱。
  • 学乐器——听清没有人声覆盖的吉他、钢琴或贝斯。想放慢而不变调，可以继续用音频变速。
  • 清唱和混音——提取人声用于翻唱、混搭或采样。
  • 扒歌词——单独的人声更容易听清，还可以用语音转文字记下来。

效果如何？

对于录音室录音，SCNet 能去掉大部分演唱，通常只在高音、混响尾音或和声处留下轻微痕迹。现场录音、重失真和很老的单声道歌曲分离得不那么干净。人声文件里可能残留一点鼓或吉他。该模型在 MUSDB18 音乐数据集上训练；在其测试歌曲上，人声分离效果优于广泛使用的 Demucs。

需要多长时间？

对浏览器来说，分离是很重的工作：在电脑上所需时间是歌曲时长的几倍，在手机上更久，还需要足够的空闲内存，所以长歌曲最好用电脑处理。页面会显示正在处理第几段以及大约还剩多少时间。

隐私

歌曲在您的浏览器中用 ONNX Runtime Web 解码和分离。页面只下载一次模型文件（13 MB）和运行库；您的音频不会被发送到任何地方。AudioTools.dev 也没有可以接收它的服务器。

常见问题

如何免费去掉歌曲里的人声？
把歌曲拖到这里，点击“消除人声”。完成后把伴奏下载为 MP3 或 WAV。完全免费，无需账号，没有限制。
我的歌曲会上传到服务器吗？
不会。分离模型在您的浏览器中运行，只会下载一次模型文件。歌曲绝不离开您的设备。
可以只提取人声（清唱）吗？
可以。您会得到两个文件：伴奏和人声，可以下载其中一个或两个都下载。
手机上能用吗？
能，适用于最新的 Chrome 和 Safari，但比电脑慢好几倍，还需要足够的空闲内存。长歌曲请用电脑。
为什么还能听到一点人声？
分离模型只能估计人声，无法完全精确。混响、和声和高音可能留下轻微痕迹，尤其是现场录音或经过大量处理的录音。
